# Catalysta Consultancy

An informative website for Catalysta Consultancy, rendered with EJS templates.

## Run locally

Install dependencies and start the Express server:

```sh
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). Pages are available at `/`, `/about`, `/services`, `/blogs`, and `/contact`. Shared navigation and footer markup live in `views/partials`.
